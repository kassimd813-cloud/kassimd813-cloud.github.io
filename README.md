# Olutomi Kassim — Portfolio (Angular)

Angular foundation for the approved mathematics educator portfolio.
The visual design is migrated from the Lovable reference project in stages;
this repository starts as a clean, static-capable Angular shell.

## Development

```bash
npm start
```

Opens the app at `http://localhost:4200/`.

## Production build

```bash
npm run build
```

Output is written to `dist/daddy-pero-cv-site/browser/` (suitable for static hosting such as GitHub Pages in a later stage).

## Stack

- Angular (standalone components, no SSR)
- TypeScript
- Standard CSS with shared design tokens in `src/styles.css`
